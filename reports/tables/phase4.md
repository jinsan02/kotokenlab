# Phase 4 — 등토큰 예산과 N 스윕

측정 2026-09-01. run `cpt_t2b_mean_eqtok_seed42`, `cpt_t2b10k_mean_main_seed42`,
`cpt_t2b10k_mean_noise_seed{42,123,2026}`, `surgery_kot2b_v2_n10000_mean_seed42`.

Phase 3 에서 T2b 는 C0 를 따라잡지 못했다 (한국어 BPB 1.5671 vs 1.1375,
[`cpt_main.md`](cpt_main.md)). 진단은 **노출 부족** 이었다 — 새 토큰 30,000개의
중앙값 발화가 168.5MB 전체에서 143회. Phase 4 는 그 진단이 가리키는 두 축을
친다: 노출을 늘리거나(등토큰), 나눠 가질 입을 줄이거나(N 스윕).

**예측을 먼저 박아 두고 시작했다** ([`../docs/PLAN.md`](../docs/PLAN.md)
"Phase 4 사전 등록"). 둘 다 "격차가 줄되 C0 를 넘지는 못한다" 였다.

### N=10,000 의 sigma — 새 조건이므로 따로 쟀다

17.5MB x seed 42/123/2026.

| 언어 | seed 42 | 123 | 2026 | sigma | 2 sigma |
|---|---:|---:|---:|---:|---:|
| 한국어 | 1.751896 | 1.749567 | 1.750824 | **0.001166** | 0.002331 |
| 영어 | 0.831140 | 0.831247 | 0.831335 | 0.000098 | 0.000195 |
| 코드 | 0.487155 | 0.487217 | 0.487099 | 0.000059 | 0.000118 |

N=30,000 의 0.001234 와 거의 같다. 손상된 조건은 손상 정도와 무관하게
sigma 가 비슷하다는 뜻이고, 보수적 상한으로 대신 써도 됐을 값이다.

## 노출 가설이 반증됐다 — Phase 3 의 진단이 틀렸다

Phase 3 에서 "중앙값 발화 143회라 못 배웠다" 고 진단했다. N=10,000 은 새 토큰이
1/3 이므로 노출이 늘어야 하고, 그러면 격차가 줄어야 한다. 노출은 실제로 늘었다:

| | 중앙값 발화 | 0회 | 100회 미만 | 1,000회 이상 |
|---|---:|---:|---:|---:|
| N=30,000 | 143 | 11.8% | 39.7% | 11.0% |
| N=10,000 | **623** | 7.2% | 15.2% | 32.7% |

**4.4배 늘었다. 그런데 회복률이 움직이지 않았다.**

| 조건 | step0 | final | 메울 거리 | 메운 거리 | **회복률** |
|---|---:|---:|---:|---:|---:|
| N=30,000 등원문 | 2.3803 | 1.5671 | 1.2428 | 0.8132 | **65.4%** |
| N=10,000 등원문 | 2.1918 | 1.4973 | 1.0543 | 0.6945 | **65.9%** |
| N=30,000 등토큰 | 2.3803 | 1.5322 | 1.2428 | 0.8481 | **68.2%** |

노출 4.4배가 산 것은 +0.5%p 다. 데이터 43% 증가(등토큰)가 산 것은 +2.8%p 다.
**데이터를 더 주는 것은 조금 듣고, 토큰당 노출을 늘리는 것은 거의 안 듣는다.**

N=10,000 의 격차가 작아 보이는 것(0.4296 -> 0.3597)은 더 잘 배워서가 아니라
**덜 망가진 채로 출발해서** 다 (step0 2.1918 vs 2.3803). 회복 *비율* 은 같다.

### 그래서 병목은 무엇인가 — 아직 모른다

CPT 는 초기 손상의 약 65% 를 회복하고 멈추는데, 그 비율이 노출과 거의 무관하다.
데이터를 43% 더 주면 68% 로 올라가므로 예산에는 반응하지만 기울기가 완만하다.
나머지 35% 를 막는 것이 무엇인지 이 데이터로는 가릴 수 없다.

유력한 후보는 `tie_word_embeddings` 다 — 각 행이 입력 표현이자 출력 로짓
방향이라, 한 벡터가 두 역할을 동시에 잘해야 한다. 노름 보정이 반증된 것
([`precpt_bpb.md`](precpt_bpb.md))과 정렬이 실패한 것
([`alignment_probe.md`](alignment_probe.md))도 같은 구조를 가리킨다.
**다만 이것은 아직 가설이고, 이 프로젝트는 아직 검증하지 않았다.**

## 새로 나온 관찰 — N 곡선이 강하게 오목하다

N=0 이면 T2b 는 정의상 C0 다 (1.1375). 그런데 N=10,000 에서 이미 1.4973 이다.

```
N        0        10,000     30,000
BPB    1.1375     1.4973     1.5671
손상      —        0.3598     0.4296
압축      0%       -25.2%     -30.2%
```

**첫 1만 개가 손상의 84% 를 내고, 다음 2만 개가 16% 를 더 낸다.** 압축도 같은
모양이다 — 첫 1만 개가 -25.2%, 나머지 2만 개가 -5.0%p 추가.

두 곡선 다 오목하므로 **N < 10,000 구간에 데이터가 없다.** 거기서 어느 쪽이 더
가파른지가 "쓸 만한 작은 N 이 있는가" 를 가른다. 이것은 오늘 결과에서 새로
나온 질문이라 사전 등록에 없다 — 사후에 끼워 넣지 않고 다음 실험으로 남긴다.

## 한계

- **seed 42 단독이다** (sigma 측정 제외). 격차가 300 sigma 이상이라 seed 로
  뒤집히지 않지만, 회복률 65.4% vs 65.9% 의 0.5%p 차이는 seed 1개짜리 값끼리의
  비교다. "거의 안 움직였다" 는 말할 수 있어도 "정확히 0.5%p" 는 못 한다
- **N 두 점으로 곡선을 말한다.** 오목하다는 것은 N=0 이 정의상 C0 라는 사실에
  기대고 있다. N=20,000 이나 N<10,000 을 재지 않았으므로 모양은 추정이다
- **등토큰은 C0 와 다른 문서를 봤다.** 풀 70,000 (C0 는 50,000)이라 셔플 순서가
  다르다. 등토큰 조건에서는 T2b 가 더 많은 원문을 봐야 하므로 애초에 같을 수
  없고, 데이터 선택 분산은 0.39 BPB 격차에 비해 무시할 수준이다
- **노출 환산의 '0회' 버킷은 상한이다.** 20MB 표본에서 0 이면 환산해도 0 이라,
  뒤쪽 문서에서 발화하는 것이 섞여 있다
- Phase 3 의 한계 두 개는 그대로다 — CPT 코퍼스가 Qwen 사전학습과 겹치고
  (C0 에 유리한 편향), E1 과 N 을 dev 에서 골라 낙관 편향이 누적됐다
  ([`cpt_main.md`](cpt_main.md) 한계 절)
