## 한계

- `d_168` 은 같은 run 의 중간 지점이다. 상수 LR 이 이어지는 중이라, 168.5MB 에서
  멈춘 run 의 종점과 학습 상태가 같지 않다
- 같은 update 는 같은 FLOPs 가 아니다 (vocab softmax 비용 등). compute-matched proxy 다
- T2b 는 같은 update 를 채우려고 원문을 약 241MB 본다 — 같은 정보량 비교가 아니다
- n=3 이다. t 구간은 정규성을 가정한 탐색적 값이다 (RULES 14c)
- seed 42 의 C0 는 회계 수정 이전 코드다 (PLAN 이 09-20 커밋별 확인으로 허용)
