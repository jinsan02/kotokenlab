## 사전 점검 — R5 의 예산 배증당 회복률 증분 (W0-9)

회복률은 상수 LR C0 를 앵커로 그 run 의 평가 지점에서 다시 계산했다.

| 예산 | 회복률 | 직전 배증 대비 증분 |
|---:|---:|---:|
| 20MB | 51.84% |  |
| 40MB | 60.10% | +8.26%p |
| 80MB | 67.28% | +7.18%p |
| 160MB | 72.14% | +4.86%p |

| 구간 | 증분 비 | 등록 구간 안인가 |
|---|---:|---|
| 40→80MB | 0.869 | 예 |
| 80→160MB | 0.677 | 예 |

등록 구간은 (0.5, 0.9] 다 — P3-A 의 예측 "감속이 이어진다" 가 이 구간이다.

**점검 통과.** R5 에서 관측된 비가 등록 구간 안이다. P3-A 를 등록된 예측 그대로 돌린다.

이 값들은 R5 의 **사후** 관측이다. P3-A 의 판정은 A 자신의 run 에서 같은 방식으로 계산한 증분 비로 내린다.
