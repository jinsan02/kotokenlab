## 사전 점검 — R5 의 예산 배증당 회복률 증분 (W0-9)

회복률은 상수 LR C0 를 앵커로 그 run 의 평가 지점에서 다시 계산했다.

| 예산 | 회복률 | 직전 배증 대비 증분 |
|---:|---:|---:|
| 20MB | 51.84% |  |
| 40MB | 60.10% | +8.26%p |
| 80MB | 67.28% | +7.18%p |
| 160MB | 72.14% | +4.86%p |

| 구간 | 증분 비 | 등록 구간 안인가 |
|---|---:|---|
| 40→80MB | 0.869 | 예 |
| 80→160MB | 0.677 | 예 |

등록 구간은 (0.5, 0.9] 다 — P3-A 의 예측 "감속이 이어진다" 가 이 구간이다.

**점검 통과.** R5 에서 관측된 비가 등록 구간 안이다. P3-A 를 등록된 예측 그대로 돌린다.

이 값들은 R5 의 **사후** 관측이다. P3-A 의 판정은 A 자신의 run 에서 같은 방식으로 계산한 증분 비로 내린다.

## 게이트 — D0 노출 구간 보정 (P3-D)

행당 노출 `count_ko` 구간 안에서만 고른다 (T2b 새 토큰 노출 중앙값의 10배 안). 학습 없음, 언어별 2MB.

| K | ko 손상 배율 | 영어 변화 |
|---:|---:|---:|
| 0 | 1.000 | +0.0% |
| 2,000 | 1.009 | +20.4% |
| 5,000 | 1.018 | +42.4% |
| 10,000 | 1.028 | +67.5% |
| 20,000 | 1.039 | +102.9% |
| 30,000 | 1.047 | +126.2% |

목표는 1차 T2b 의 배율 2.058 ± 0.05 이고, K 상한은 30,000 다 (등록).

**불통과.** K=30,000 에서도 배율이 1.047 에 그친다 (목표 2.058).

**D2 를 돌리지 않는다.** 등록에 적어 둔 그대로, 이것 자체가 결과다 —
기존 어휘를 망가뜨리는 방법으로는 **행당 노출과 손상 크기를 동시에**
T2b 에 맞출 수 없다. 드물게 쓰이는 행은 많이 망가뜨려도 한국어 BPB 를
거의 못 움직인다.

부수 피해도 다르다 — 같은 K 에서 영어가 +126.2% 다. 1차 T2b 는 영어가 거의 그대로였다 (+0.1%). 한국어 배율만 맞춰도
"같은 손상" 이라고 부를 수 없다는 뜻이다.
