# T2a(축소) vs T2b(치환) — N 스윕

측정 2026-08-30. v1 dev 259.2MB / 63,961문서. 기준선 `qwen_original`.
run `tok_bench_sweep`, `tok_bench_sweep50k`, `tok_bench_v2sweep`, `tok_bench_v2`.

T2a 와 T2b 는 각 N 에서 **같은 `prune_<N>.tsv`** 를 쓴다. 다른 것은 비운 슬롯을
그대로 두느냐(T2a) 한국어 토큰으로 채우느냐(T2b) 뿐이다.

기증자 채굴은 두 판이 있다. **v2 를 쓴다.**

    v1  인접 토큰 쌍을 그냥 셌다
    v2  pretokenizer 세그먼트 안쪽 쌍만 셌다  <- 채택

## 왜 v1 이 손해였나 — pretokenizer 경계

Qwen 의 Split 정규식은 BPE 이전에 문자열을 자른다.

```
(?i:'s|'t|...)|[^\r\n\p{L}\p{N}]?\p{L}+|\p{N}| ?[^\s\p{L}\p{N}]+[\r\n]*|...
                                        ^^^^^  숫자는 한 자씩 고립
```

숫자는 낱개로 갈리고 글자(`\p{L}+`)와 구두점은 다른 세그먼트가 된다. BPE 는
세그먼트 안에서만 병합하므로 `" 1"`, `"20"`, `"다."` 같은 쌍은 **merge rank 를
어떻게 줘도 절대 발화하지 않는다.**

v1 은 이 확인 없이 셌고, 전체 인접쌍의 **43.8%** 가 경계를 넘는 것이었다.
채굴 빈도 10만회 이상인 최상위 기증자 6개가 발화율 0% 였다.

| dev 20,000문서 (1,686만 토큰) | 활성 슬롯 | 기증 토큰 점유 |
|---|---:|---:|
| T2b v1 n=30,000 | 17,689 / 30,000 (59.0%) | 39.6% |
| **T2b v2 n=30,000** | **27,864 / 30,000 (92.9%)** | **43.3%** |

## 무엇을 사는가

T2a 가 못한 것이 아니다. **사는 물건이 다르다.**

| | 얻는 것 | 잃는 것 |
|---|---|---|
| T2a n=30,000 | embedding 26.9M 파라미터 감소 (136.1M 의 19.7%) | 압축 이득 0 |
| T2b v2 n=30,000 | 한국어 −30.2%, 코드 −0.8% | 파라미터 감소 0 |

제거 대상이 코퍼스에서 거의 안 쓰이므로(3만개 제거 시 13.6억 토큰 중 0.0035%),
지우기만 해서는 토큰화가 바뀔 이유가 없다. 압축을 얻으려면 **그 자리를 채워야
한다** — 이것이 T2b 의 주장이다.

## 외부 참조와의 위치

같은 dev 에서 잰 값이다 (run `tok_bench_v1`).

| | 한국어 | 영어 | 코드 | vocab |
|---|---:|---:|---:|---:|
| HCX-SEED-0.5B | −24.9% | +0.0% | +17.6% | 110,524 |
| A.X-4.0-Light | −39.4% | +7.3% | +22.5% | 102,400 |
| **T2b v2 n=30,000** | **−30.2%** | **−0.0%** | **−0.8%** | **151,643 (유지)** |

T2b 는 HCX 보다 한국어 압축이 크면서 코드 손해가 없다. A.X 는 한국어가 더 좋지만
코드에서 +22.5% 를 낸다. 스펙 §16 이 경고한 trade-off 를 T2b 는 치르지 않는다 —
기존 토큰을 대체하는 것이 아니라 **안 쓰이는 자리** 를 쓰기 때문이다.

v2 는 n=10,000 만으로도 HCX(−24.9%) 를 넘는다.

## 선택: N = 30,000, 기증자 v2

한계이득이 25.2 → 3.5 → 1.5%p 로 반감한다. 더 밀면 제거 비용이 빠르게 오르고
(50,000 에서 10배) T2a 코드가 악화되기 시작한다. CPT 는 이 하나로만 돌린다.

남은 미발화 2,136개(7.1%)는 인접쌍끼리의 경쟁이다 — (A,B) 와 (B,C) 가 같은 B 를
두고 다투므로 둘 다 발화할 수 없다. 라운드를 더 돌리면(Phase B) 줄일 수 있지만
라운드마다 코퍼스를 다시 토큰화해야 하고, 남은 여지가 7% 라 지금은 하지 않는다.
